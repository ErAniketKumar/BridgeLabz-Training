Project : Global Pandemic Intelligence System
Scenario
A healthcare analytics company wants to build a pandemic monitoring system using worldwide disease data similar to COVID datasets.
The system should track:


Daily cases

Deaths

Vaccinations

Population analysis

Continent-level trends

Vaccination effectiveness

Foreign Keys

Bulk insert daily records

Delete duplicate vaccination records


Part C — Advanced Analytical Queries
Queries to Build
1. Infection Rate Analysis
Find:


Top 10 countries with highest infection rate

Infection percentage vs population


2. Death Percentage
Calculate:


Local death %

Global death %

Continent-wise death %


3. Vaccination Analytics
Using JOINS between deaths and vaccination tables:
Find:


Percentage of population vaccinated

Fully vaccinated population

Booster dose percentage

Daily vaccination growth


4. CTE-Based Trend Analysis
Using CTE:


Find 7-day moving average of cases

Find countries where infection continuously increased for 5 days


5. Ranking Queries
Using:


ROW_NUMBER()

RANK()

DENSE_RANK()

Find:


Top infected countries per continent
